# Tradex Hackathon Spring 2026 — Инструкция по сборке лендинга

Документ для разработчика/AI-агента, который будет собирать одностраничный лендинг хакатона. Содержит структуру блоков, стек, визуальный язык, контент-каркас и пошаговый план работ. Отражает фактическое состояние реализованного лендинга.

---

## 1. Контекст и цели

**Что это:** одностраничный промо-лендинг внутреннего двухдневного хакатона Tradex Hackathon Spring 2026 (27–28 мая 2026).

**Для кого:** участники хакатона (команды разработки, дизайна, продукта). Внутренняя аудитория, без публичной индексации.

**Зачем нужен лендинг:**
1. Собрать в одном месте бриф, расписание и правила.
2. Показать состав участников и команд, дать визуальное «мы вместе».
3. Задать вайб мероприятия — лендинг сам должен «кайфовать» вместе с участниками.

**Тональность:** футуристичная, космическая, лёгкая. Не сухой корпоратив.

## 2. Технологический стек

| Слой | Решение | Зачем |
|---|---|---|
| Разметка | HTML5 (один `index.html`) | Простота, без сборщиков |
| Стили | CSS (один `styles.css`, CSS-переменные для палитры) | Быстро править, no-build |
| Скрипты | Vanilla JS (модули в `/scripts`) | Минимум зависимостей |
| Анимации | [GSAP 3](https://gsap.com/) + плагин [Flip](https://gsap.com/docs/v3/Plugins/Flip/) + [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) | FLIP-перегруппировка, скролл-эффекты |
| Частицы hero | Canvas 2D (свой код, без библиотек) | Контроль производительности |
| Навигация/scrollspy | `IntersectionObserver` (нативный) | Без зависимостей |
| Шрифты | Google Fonts: `Space Grotesk` (заголовки) + `Inter` (текст) | Современная футуристика |
| Хостинг | GitHub Pages | Бесплатно, статический сайт |

Подключения через CDN — без `npm`, без сборки.

### 4.2. Типографика

- Заголовки: `Space Grotesk`, веса 500/700, `letter-spacing: -0.02em`.
- Текст: `Inter`, веса 400/500.
- Размеры (clamp для отзывчивости):
  - H1 hero: `clamp(2.5rem, 7vw, 5.5rem)`
  - H2 секций: `clamp(1.8rem, 3.5vw, 3rem)`
  - Body: `clamp(0.95rem, 1.1vw, 1.05rem)`
- Hero-заголовок — с эффектом «split-text»: каждая буква появляется по очереди (ручное разбиение на `<span class="split-char">` в `scroll-effects.js`).

### 4.3. Эффекты и тон

- **Стекло:** карточки — `backdrop-filter: blur(12px)` + `background: rgba(17, 22, 52, 0.6)` + тонкая граница.
- **Glow:** акцентные элементы — `box-shadow: 0 0 40px rgba(99, 102, 241, 0.4)`.
- **Градиентная неоновая рамка:** через `mask-composite` (навигация, hover-карточки критериев).
- **Curved borders:** `border-radius: 16–24px` для карточек, `999px` для кнопок, чипов и навигации.
- **Парение:** scroll-hint и логотип-планета — мягкая пульсация/float.
- **Курсор:** стандартный.

## 6. Детальное описание каждого блока

### 6.0. НАВИГАЦИЯ (floating glass capsule)

**Вид:** плавающая капсула (`border-radius: pill`) с glass-фоном (`blur(20px) saturate(140%)`), неоновой градиентной рамкой (фиолетовый → циан через `mask-composite`) и мягким свечением. Отступ сверху 16px.

**Содержит:**
- Слева — логотип: пульсирующая планета (фиолетовый ↔ циан) + текст `Tradex`.
- Справа — ссылки: О хакатоне · Метрика · Пользователи · Экипаж · Маршрут · Критерии · Призы · FAQ.

**Поведение (`main.js → initNav`):**
- Скрыта на hero (`translateY(-160%)`, `opacity: 0`, `pointer-events: none`).
- Появляется, как только hero (ровно 100vh) полностью ушёл за верхнюю кромку — т.е. со второй секции. Через `IntersectionObserver` на `#hero`, `!entry.isIntersecting`.
- **Scrollspy:** активный пункт подсвечивается градиентным pill при попадании секции в зону `rootMargin: '-45% 0px -50% 0px'`.
- Клик по ссылке → плавный скролл к секции (`scroll-margin-top: 76px` на секциях, чтобы не уезжали под капсулу).

**Адаптив:** на ширине ≤980px ссылки скроллятся горизонтально; ≤720px — текст лого скрывается, остаётся планета.

### 6.1. HERO

**Содержит (строго по вертикали, по центру):**
- Дата-плашка (чип): `27–28 мая 2026`.
- Заголовок: `Tradex Hackathon` / `Spring 2026` (вторая строка — градиентный текст).
- Подзаголовок: `Два дня. Одна метрика. Бесконечно идей.`
- Подпись: `До окончания хакатона`.
- Countdown-таймер до **окончания** `2026-05-28 18:00` (формат `DD : HH : MM : SS`).
- CTA-кнопка `Узнать всё` (со стрелкой вниз) → плавный скролл к «О хакатоне».
- Фон: `canvas`-анимация (см. ниже) + scroll-hint снизу.

> Важно: `.hero__content` — это `display: flex; flex-direction: column; align-items: center`. Все элементы (включая таймер и кнопку) идут друг под другом, не в одну горизонтальную линию.

**Анимация фона (`starfield.js`):**
- Слой 1: ~220 мерцающих «звёзд» (мерцание через `Math.sin`).
- Слой 2: ~40 «частиц», летящих от центра наружу.
- Слой 3: до 2 «комет» — длинный градиентный шлейф, появляются редко.
- Цвета — из палитры (`--accent-violet`, `--accent-cyan`).
- Останавливается при `document.hidden`; при `prefers-reduced-motion` canvas не показывается.

**Появление контента (GSAP timeline):**
1. Дата-чип: y+20 → 0.
2. Split-заголовок: буквы появляются с stagger 0.025 с (rotateX).
3. Подзаголовок: fade + y.
4. Подпись countdown: fade + y.
5. Countdown: scale 0.85 → 1 (`back.out`).
6. CTA: fade + y, на hover — подъём + усиление glow.

### 6.3. ГЛАВНАЯ МЕТРИКА — retention_d1_d6

**Заголовок:** `retention_d1_d6` (градиентный текст), kicker «Главная метрика».

**Подпись:** `Доля новичков, активных на 6-й день после первого визита. Всё, что мы делаем — двигаем именно её.`

**Визуал — SVG retention-кривая** (`viewBox 0 0 740 360`):
- Классическая L-форма: резкое падение D0 (100%) → D1, плавный хвост D1→D6.
- Точки и подписи значений: D0 100% · D1 29,1% · D2 20,2% · D3 15,9% · D4 13,3% · D5 11,6% · D6 10,5%.
- Ось Y 0–100% с грид-линиями, ось X — дни (D0…D6), подпись «ДНИ ПОСЛЕ ПЕРВОГО ВИЗИТА».
- Подсвеченная пунктиром зона `ЗОНА RETENTION_D1_D6` (D1→D6). Ключевые точки D1 (фиолетовая) и D6 (циан, крупнее) выделены.

**Анимация (ScrollTrigger):** появление зоны → отрисовка линии (`stroke-dashoffset`) → заливка area → всплывание точек → проявление подписей значений.

**Аннотации под графиком (2 карточки):**
- `−60%` — уходят сразу после первой сессии.
- `≈40%` — доживают c D1 до D6.

**Caption:** `Каждый процентный пункт между D1 и D6 — это живые пользователи, которых вы вернули.`

### 6.5. УЧАСТНИКИ И КОМАНДЫ

**Заголовок:** `Те, кто полетят`, kicker «Экипаж».
**Лид:** `16 человек ждут запуска двигателей по четырём капсулам.`

**Карточка участника:**
- Круглый аватар: инициалы белым на уникальном градиенте (детерминированно по хэшу имени).
- Имя.
- Подпись команды (показывается только в режиме «по командам»).

**Взаимодействие — кнопка-распределитель (НЕ toggle):**
- Под плитками — одна центральная кнопка `Распределить по командам`.
- Изначально: 16 участников показаны плитками в случайном порядке, без указания команд.
- По клику (`participants.js → runDistribution`):
  1. Кнопка → состояние «Распределяю…», иконка крутится.
  2. 3 быстрых «псевдо-рандомных» перетасовки плиток (GSAP Flip, `from: 'random'`).
  3. Финальный плавный переход плиток в группы по командам (GSAP Flip, `absolute: true`).
  4. Кнопка → `Перетасовать заново`. Повторный клик возвращает к плиткам.
- Распределение по факту фиксированное (из JSON), «рандом» — только визуальный эффект.

## 7. Анимации и интерактив — сводка

| Навигация | scroll (после hero) | Выезд floating-капсулы + scrollspy подсветка |

| Timeline | ScrollTrigger | Появление этапов с stagger |

| Призы | mousemove | Tilt ±6° |

**Перформанс:**
- ScrollTrigger и hero-intro учитывают `prefers-reduced-motion` (статичные конечные состояния).
- Canvas — `requestAnimationFrame`, пауза при `document.hidden`.
- Картинок нет — нечего lazy-load'ить.

## 10. Пошаговый план сборки

1. **Каркас.** `index.html`, `styles.css`, `scripts/main.js`. Подключить шрифты и GSAP. Прописать CSS-переменные. Пустые секции с id `hero`, `about`, `metric`, `users`, `participants`, `timeline`, `criteria`, `checklist`, `prizes`, `faq`.

## 12. Деплой на GitHub Pages — короткий чек-лист

1. Создать репозиторий (приватный, чтобы лендинг не индексировался).
2. Запушить файлы.
3. Settings → Pages → Source: `main`, папка `/ (root)`.
4. Дождаться билда, открыть `https://<username>.github.io/<repo>/`.
5. Прислать ссылку организатору.

> Локальный запуск: `python3 -m http.server 8080` (нужен сервер — `fetch` для JSON не работает по `file://`).

## 13. Чего не делаем

- Не пишем серверную часть, формы регистрации, email-рассылки.
- Не добавляем мультиязычность.
- Не делаем CMS — все тексты правим прямо в HTML / JSON.
- Не подключаем аналитику, кук-баннеры, GDPR — внутренний лендинг.
- Не вставляем реальные фото — только сгенерированные аватары.
- Не делаем тёмную/светлую тему — только тёмная deep-space.
